# ระบบบัญชีร้านอาหาร (หลายสาขา) — Node.js + PostgreSQL · เวอร์ชัน 3.0

ระบบบัญชีอย่างเดียว (ไม่มีระบบขาย POS) แยกบัญชีตามสาขา ทุกคนต้องเข้าสู่ระบบก่อนใช้งาน และเห็นเฉพาะเมนูที่ได้รับสิทธิ์

## มีอะไรบ้าง

- **หลายสาขา**: Admin สร้างสาขาได้ไม่จำกัด แต่ละสาขามีบัญชี สต็อก พนักงาน และเงินเดือนแยกกัน
- **บัญชี**: รายรับ / รายจ่าย / สินทรัพย์ (หลายบรรทัด ส่วนลด VAT 7% แนบใบเสร็จ) เลขที่เอกสารอัตโนมัติ ค้างรับ-ค้างจ่าย สมุดบัญชี เงินในบัญชี พิมพ์ / PDF / Excel
- **ภาพรวม** (ใหม่):
  - **รายได้เฉลี่ย** — เฉลี่ยต่อวันที่มีรายรับ, เฉลี่ยต่อวันตามปฏิทิน (ช่วงที่ยังไม่จบนับถึงวันนี้), ค่าใช้จ่ายเฉลี่ยต่อวัน, กำไรเฉลี่ยต่อวัน, ยอดเฉลี่ยต่อเอกสาร, วันที่ขายได้สูงสุด/ต่ำสุด และค่าเฉลี่ยแยกตามวันในสัปดาห์
  - **เงินเข้า-ออกแต่ละบัญชี** (ใหม่ 2.3) — แต่ละบัญชี (เงินสด, โอนเงิน/พร้อมเพย์ ฯลฯ) แสดง ยอดต้นงวด + รับเข้า (เขียว) − จ่ายออก (แดง) = คงเหลือ (น้ำเงิน) ตามช่วงวันที่ที่เลือก และยอดรวมทุกบัญชี
  - **สรุปตามช่องทางรับ/ชำระเงิน** — แต่ละช่องทางรับเท่าไหร่ จ่ายเท่าไหร่ สุทธิเท่าไหร่ แยกช่องทางเครดิต (บัตรเครดิต แอปเดลิเวอรี่รอโอน) และรายการที่ยังค้าง/ไม่ระบุช่องทางออกมาชัดเจน
- **ผู้ใช้งาน & สิทธิ์** (ใหม่): Admin สร้างผู้ใช้ได้หลายคน กำหนดได้ว่าแต่ละคน
  - เข้าสาขาไหนได้ (เลือกหลายสาขา หรือทุกสาขา)
  - แต่ละเมนู **ไม่เห็น / ดูอย่างเดียว / แก้ไขได้** (15 เมนู) — มีชุดสำเร็จรูป เช่น “พนักงานร้าน (สต็อกอย่างเดียว)”
  - เป็นผู้อนุมัติหรือไม่: อนุมัติสต็อก / อนุมัติการลา / อนุมัติเบิกเงิน
  - เซิร์ฟเวอร์ตรวจสิทธิ์ทุกครั้ง (ไม่ใช่แค่ซ่อนเมนู) · ผู้ใช้ใหม่ต้องเปลี่ยนรหัสเมื่อเข้าครั้งแรก · เปลี่ยนรหัสของตัวเองได้
- **สต็อก (ปรับใหม่ 2.5 — ใช้ง่ายบนมือถือ)**:
  - แท็บ **เบิกของ**: ด้านบนสุดเป็นแถบ **เบิกล่าสุด** (วันนี้ / เมื่อวาน — ใคร เบิกอะไร กี่หน่วย กี่โมง) · ปุ่มหมวดเรียงเป็นแถว + ช่องค้นหา + ปุ่ม “⚠ ใกล้หมด” · สินค้าเป็นการ์ดแยกกลุ่มตามหมวด แตะการ์ดแล้วกด − / + ใส่จำนวน เลือกได้หลายอย่าง แล้วกด **เบิก** ครั้งเดียว
  - **เบิกใช้ = ตัดสต็อกทันที ไม่ต้องอนุมัติ** · **รับเข้า/เติม · ของเสีย · ตรวจนับ · ยอดยกมา** ของคนที่ไม่มีสิทธิ์อนุมัติ = **รออนุมัติ** ยังไม่กระทบยอด จนผู้จัดการกดอนุมัติ
  - พนักงาน **แก้ไข / ลบการเบิกของตัวเองได้ภายในวันเดียวกัน** (กด “แก้ไข” ที่แถบเบิกล่าสุด) — การแก้ทุกครั้งบันทึกใน Log (จำนวนเดิม → ใหม่) · ผู้อนุมัติสต็อกแก้ได้ทุกรายการ
  - **หมวดหมู่**: เลือกหมวดตอนเพิ่มสินค้าแบบแตะปุ่ม หรือพิมพ์หมวดใหม่ได้เลย · ปุ่ม **จัดการหมวด** ในหน้าสต็อก (เพิ่ม / เปลี่ยนชื่อ / เรียงลำดับ / ลบแล้วย้ายสินค้าไปหมวดอื่น) สำหรับผู้อนุมัติสต็อกหรือผู้มีสิทธิ์ตั้งค่าหมวด
  - แท็บ **ตารางคงเหลือ** และ **ประวัติความเคลื่อนไหว** แบบเดิมยังอยู่ (ต้นทุนเฉลี่ย มูลค่า บัตรสต็อก CSV)
- **ใหม่ 3.0 — ระบบ POS ขายหน้าร้าน (เลือกเปิดแยกแต่ละสาขา)**:
  - **เปิดใช้**: Admin → จัดการสาขา → แก้ไขสาขา → ติ๊ก “เปิดใช้ระบบ POS ขายหน้าร้าน” → เมนูซ้ายของสาขาจะมีกลุ่ม **POS ขายหน้าร้าน**
  - **สิทธิ์ผู้ใช้**: “POS ขายหน้าร้าน / ออเดอร์” (แคชเชียร์) และ “POS ตั้งค่าเมนู & รายงาน” (ผู้จัดการ) · มีชุดสิทธิ์สำเร็จรูป “แคชเชียร์ / พนักงานหน้าร้าน”
  - **ขายหน้าร้าน**: เมนูมีรูป แยกหมวด ค้นหาได้ → แตะเมนู (เมนูไม่มีตัวเลือก = เพิ่มทันที) → เลือกแบบ/ขนาด, Add-on, จำนวน, หมายเหตุ → ตะกร้า → **ชำระเงิน**: QR โอนเงิน (สร้าง QR ตามยอดอัตโนมัติ แนบสลิปได้) · **เงินสด** (ปุ่มแบงก์ลัด + คำนวณเงินทอน) · ช่องทางอื่น · ส่วนลด → ได้ **เลขคิวรายวัน** + พิมพ์ใบเสร็จ 80 มม.
  - **ภาษาสำหรับพนักงาน**: ไทย / English / မြန်မာ / ລາວ (ปุ่มด้านบน) · ใส่ชื่อเมนูภาษาอื่นได้ในหน้าแก้ไขเมนู
  - **ออเดอร์ / คิว**: รอทำ → กด “ทำเสร็จ” (ย้อนกลับได้) · ดูสลิป · พิมพ์ซ้ำ · **ยกเลิกทั้งบิล หรือคืนเงินบางส่วน** (ต้องใส่เหตุผล · บิลวันก่อนต้องเป็นผู้ดูแล POS) · อัปเดตเองทุก 8 วินาที
  - **จอลูกค้า**: เมนู & ตั้งค่า POS → แท็บ “จอลูกค้า” → เปิดลิงก์บนแท็บเล็ต/ทีวี (ไม่ต้องล็อกอิน) แสดงรายการในตะกร้า · QR ตามยอด · เลขคิวหลังจ่าย · กระดานคิว “กำลังทำ / เสร็จแล้ว”
  - **เมนู**: รูป, หมวด (ตั้งลำดับหมวดได้), ราคา, แบบ/ขนาด, Add-on, **จำนวนขายต่อวัน**, ปุ่ม “หมด” ชั่วคราว, เลื่อนลำดับ
  - **บัญชีรับเงิน QR**: พร้อมเพย์ (เบอร์/เลขบัตร) หรือ QR ร้านค้า (ถุงเงิน ฯลฯ — อ่านจากรูปได้บน Chrome หรือใช้นำเข้า) · ปุ่ม “ทดสอบ QR ฿1”
  - **ลงบัญชีอัตโนมัติ**: ยอดขายเข้าเป็น “รายรับ” **1 เอกสารต่อวันต่อช่องทาง** (เช่น เงินสด / โอน) · ยกเลิก/คืนเงินแล้วยอดปรับเอง · เอกสารเหล่านี้ล็อกไว้ แก้ที่ POS เท่านั้น · เลือกหมวดรายรับและช่องทางได้
  - **รายงานขาย POS**: ยอดสุทธิ, จำนวนบิล, เฉลี่ยต่อบิล, ยกเลิก, กราฟรายวัน, เมนูขายดี, ตามช่องทาง, ตามช่วงเวลา
  - **นำเข้าจาก POS เดิม**: เมนู & ตั้งค่า POS → แท็บ “นำเข้าจาก POS เดิม” → ใส่ลิงก์ POS เดิม → ได้เมนูทั้งหมด (รูป/แบบ/Add-on) + บัญชี QR มาเลย (ไม่แตะข้อมูลในระบบเดิม)
  - ไม่รวมส่วนการเงินของ POS เดิม (ใช้ระบบบัญชีนี้แทน) และการอ่านสลิปด้วย AI
- **ใหม่ 2.9 — กำไรรวมสต็อก / หลายธุรกิจ**:
  - **กำไรสุทธิรวมสต็อก** (หน้าภาพรวม + ภาพรวม Admin): กำไร = รายรับ − รายจ่าย + (สต็อกปลายงวด − สต็อกต้นงวด − ของที่รับเข้าเองไม่ผ่านรายจ่าย) · นับเฉพาะรายการสต็อกที่ **อนุมัติแล้ว** (มีรายการรออนุมัติจะแจ้งว่ายังไม่นับ) · แตะการ์ดกำไรเพื่อดูวิธีคิดทีละบรรทัด · สูตรเดียวกับต้นทุนขายในงบกำไรขาดทุน
  - **หลายธุรกิจ** (Admin → ธุรกิจ): เพิ่มธุรกิจอื่นที่ไม่เกี่ยวข้องกันได้ (เช่น ร้านกาแฟ ร้านค้า) แต่ละธุรกิจมี ชื่อ/โลโก้/เลขผู้เสียภาษี/ที่อยู่ บนเอกสาร · หมวดหมู่/ช่องทาง (ใช้ร่วมกันเฉพาะสาขาในธุรกิจเดียวกัน) · สาขา · ภาพรวม แยกกันหมด ตัวเลขไม่ปนกัน
    - ข้อมูลเดิมทั้งหมดอยู่ใน “ธุรกิจหลัก” (ใช้ชื่อ/โลโก้บริษัทเดิม) ไม่มีอะไรหาย
    - สลับธุรกิจที่ปุ่มด้านบนของหน้า Admin · หน้า “จัดการสาขา / หมวด & ช่องทาง / ภาพรวม / ตั้งค่าบริษัท” แสดงเฉพาะธุรกิจที่เลือก
    - หน้าแรกแยกกลุ่มสาขาตามธุรกิจ · โยกของข้ามสาขาได้เฉพาะในธุรกิจเดียวกัน · ย้ายสาขาไปธุรกิจอื่นได้ที่แก้ไขสาขา
- **ใหม่ 2.8 — สิทธิ์พนักงานสต็อก / ใบขอซื้อ (PO) / โยกของข้ามสาขา / บัญชีของฉัน**:
  - **ออกจากระบบ**: แตะรูปโปรไฟล์มุมขวาบน → “บัญชีของฉัน” → ปุ่มแดง **ออกจากระบบ** (หรือเมนูซ้ายล่าง “ออกจากระบบ”)
  - **รูปโปรไฟล์**: ผู้ใช้ตั้งรูปของตัวเองได้ในเมนู “บัญชีของฉัน” · เข้าด้วยรหัสสาขา = แสดงโลโก้สาขา · โลโก้หน้าแรก/หน้าเข้าสู่ระบบใหญ่ขึ้น
  - **หน้าสต็อกแบบโหมด**: ปุ่มใหญ่ด้านบน **เบิกของ · รับเข้า/เติม · ของเสีย · โยกไปสาขาอื่น** → แตะการ์ดสินค้า ใส่จำนวน/หน่วย/ราคา **ในการ์ดเลย** เลือกได้หลายอย่าง → กดปุ่มแถบล่าง → หน้าต่างยืนยันเหมือนตอนเบิก
  - **สิทธิ์พนักงาน** (ผู้ใช้ที่ไม่มีสิทธิ์ “อนุมัติสต็อก”): เห็นแค่ **เบิกของ** (ตัดทันที) และ **ของเสีย** (รออนุมัติ) + แท็บ **รายการที่จะซื้อ** · ไม่เห็นรับเข้า/เติม · ตรวจนับ · ตารางคงเหลือ · ประวัติ · เพิ่ม/แก้ไขสินค้า (ระบบหลังบ้านบล็อกด้วย)
  - **รายการที่จะซื้อ → ใบขอซื้อ (PO)**: ติ๊กของที่ต้องซื้อ (ของใกล้หมดขึ้นให้เอง) → ใส่จำนวน/หน่วย → **ส่งขออนุมัติ** → ได้เลข PO (เช่น PO2611-001) **พิมพ์ PO ได้ทันที** · ผู้จัดการกด **อนุมัติ / ไม่อนุมัติ** (ไม่อนุมัติ = รายการกลับไปที่ลิสต์) · ซื้อมาแล้วผู้จัดการกด “ติ๊กของที่ซื้อแล้ว” → ใส่ราคาจริง → รับเข้าสต็อก · ซื้อครบ = PO ปิดเอง · พนักงานยกเลิกคำขอของตัวเองได้ระหว่างรออนุมัติ
  - **โยกของข้ามสาขา** (ผู้จัดการ/ผู้อนุมัติสต็อก): โหมด “โยกไปสาขาอื่น” → เลือกของ + จำนวน → เลือกสาขาปลายทาง → สาขานี้ตัดสต็อกทันที (ต้นทุนเฉลี่ยตามสาขาต้นทาง) · สาขาปลายทางเห็นใน “รออนุมัติ” → อนุมัติ = เข้าสต็อก · **ไม่อนุมัติ = ของคืนสาขาต้นทางอัตโนมัติ** · ปลายทางยังไม่มีสินค้านี้ ระบบสร้างให้ (ชื่อเดียวกัน) · ประวัติแสดง “โยกออก → / รับโยก ←”
- **ใหม่ 2.7 — สต็อกหลายหน่วย / รับเข้าแบบแยกหมวด / รายการที่จะซื้อ**:
  - **หลายหน่วยต่อสินค้า**: แก้ไขสินค้า → “หน่วยหลัก” (หน่วยที่นับสต็อก เช่น กก.) + “หน่วยอื่น” เช่น 1 ถุง = 2 กก., 1 ลัง = 24 กก.
    - ตอนรับเข้า / เบิก / ของเสีย / ตรวจนับ / แก้ไขการเบิก เลือกหน่วยได้ ระบบแปลงเป็นหน่วยหลักให้
    - ราคาที่ใส่ = **ราคาต่อหน่วยที่เลือก** เช่น 3 ถุง × 62.50 → สต็อก +6 กก. ต้นทุน 31.25 / กก. (ราคาต่อถุงตรงความจริง ต้นทุนต่อ กก. ถูกต้อง)
    - รายจ่ายที่ผูกสต็อก: ใส่หน่วยในบรรทัดเป็น “ถุง” ได้เลย ระบบแปลงเป็น กก. ให้ (ปุ่มเขียวจะบอก “= 4 กก.”)
    - ประวัติ / เบิกล่าสุด แสดงทั้งหน่วยที่ใส่และหน่วยหลัก เช่น “−1 ถุง = 2 กก.”
  - **รับเข้า / เติม · ของเสีย · ตรวจนับ (ออกแบบใหม่)**: แตะปุ่มหมวด → แตะการ์ดสินค้า (หลายอย่างได้) → ใส่จำนวน · หน่วย · ราคาต่อหน่วย เห็นยอดรวมก่อนบันทึก (กติกาอนุมัติเหมือนเดิม)
  - **รายการที่จะซื้อ (Check List)** — แท็บใหม่ในหน้าสต็อก:
    - ของที่เหลือ ≤ จุดสั่งซื้อ ขึ้นมาให้อัตโนมัติ (ตั้ง “จุดสั่งซื้อ” ที่แก้ไขสินค้า) แยกตามหมวด
    - กด **เพิ่มรายการ** เลือกจากสินค้าในสต็อก หรือพิมพ์ของที่ไม่อยู่ในสต็อก (ถุงขยะ น้ำยาล้างจาน ฯลฯ)
    - ติ๊ก ☐ เมื่อซื้อแล้ว → ใส่จำนวน + หน่วย + ราคา → **รับเข้าสต็อกให้ทันที** (คนที่ไม่มีสิทธิ์อนุมัติ = รอผู้จัดการอนุมัติ) · ของนอกสต็อกติ๊กอย่างเดียว
    - ติ๊กผิดกด **ยกเลิก** ได้ (คนติ๊กเอง วันเดียวกันหรือยังรออนุมัติ / ผู้อนุมัติสต็อกได้ทุกรายการ) — รายการรับเข้าที่สร้างไว้จะถูกลบด้วย
    - รายการที่ซื้อแล้วแสดง 3 วันล่าสุด กด “ล้างรายการที่ซื้อแล้ว” ได้
- **ใหม่ 2.6 — รูปภาพ & คัดลอก**:
  - **คัดลอกเอกสาร**: เปิดรายรับ/รายจ่ายเดิม → กด **คัดลอก** ได้ฟอร์มใหม่ที่กรอกให้ครบ (ผู้ขาย รายการ หมวด จำนวน ราคา ช่องทาง ส่วนลด VAT ผูกสต็อก) วันที่ = วันนี้ ไม่คัดลอกไฟล์แนบ แก้แล้วกดบันทึกเป็นเอกสารใหม่
  - **รูปแนบแสดงเป็นรูปย่อ** ในรายการเอกสาร (มีตัวเลขบอกถ้าแนบหลายรูป) แตะรูปย่อ = เปิดดูรูปเต็มจอในหน้าเดิม เลื่อนซ้าย-ขวาดูรูปถัดไปได้ · ในเอกสารแตะรูปก็เปิดดูแบบเดียวกัน (PDF เปิดแท็บใหม่)
  - **ผูกสต็อก (ปรับใหม่)**: ใต้ชื่อรายการในรายจ่ายมีปุ่ม “📦 ผูกสต็อก” → เลือกสินค้าจากรายการ (ค้นหาได้ มีรูป) หรือ **สร้างสินค้าใหม่ในสต็อก** ได้ทันที → ปุ่มเปลี่ยนเป็นสีเขียว “หมูสับ · รับเข้า 10 กก. @ 115” กด × เพื่อเลิกผูก
    - หลักการ: กด **บันทึก** รายจ่ายแล้ว ระบบ **รับของเข้าสต็อกให้อัตโนมัติ** ตามจำนวนในบรรทัด ต้นทุน/หน่วย = ราคาหลังหักส่วนลด ไม่ต้องรออนุมัติ · แก้เอกสาร = สต็อกปรับตาม · ลบเอกสาร = ยอดที่รับเข้าหายไปด้วย
  - **รูปโปรไฟล์ / โลโก้สาขา**: Admin → จัดการสาขา → แก้ไข → เลือกรูป — แสดงแทนรหัสสาขาที่หน้าแรก เมนูด้านซ้าย และหน้าเช็คอิน
  - **รูปสินค้าสต็อก**: เพิ่ม/แก้ไขสินค้า → เลือกรูปหรือถ่ายรูป — แสดงในการ์ดเบิกของ ตารางคงเหลือ และหน้ารายละเอียดสินค้า (พนักงานเบิกถูกชิ้น)
  - **พนักงาน: รูปโปรไฟล์ + เอกสาร** — รูปแสดงในรายชื่อพนักงาน · แนบเอกสาร (บัตรประชาชน ทะเบียนบ้าน สัญญาจ้าง ใบรับรองแพทย์ สมุดบัญชี ใบอนุญาตทำงาน ฯลฯ) รูปหรือ PDF ไม่เกิน 8MB ต่อไฟล์ สูงสุด 30 ไฟล์ต่อคน · ดูได้เฉพาะผู้มีสิทธิ์เมนูพนักงาน/เงินเดือน แนบ/ลบได้เฉพาะสิทธิ์แก้ไขพนักงาน
  - **คัดลอกสินค้าสต็อกไปสาขาอื่น (เลือกทีละรายการได้)**: Admin → หมวด & ช่องทาง → **คัดลอกสินค้าสต็อก** หรือ เข้าสาขาในฐานะ Admin → สต็อก → **คัดลอกไปสาขาอื่น** (หรือปุ่มในหน้ารายละเอียดสินค้า) → ติ๊กสินค้าที่ต้องการ เลือกสาขาปลายทาง — คัดลอกเฉพาะ **ชื่อ รหัส หมวด หน่วย จุดสั่งซื้อ หมายเหตุ รูป** **ไม่คัดลอกจำนวนคงเหลือและต้นทุน** (เริ่มที่ 0) · ถ้าปลายทางมีชื่อซ้ำจะข้าม หรือเลือก “อัปเดตรายละเอียด” ได้ (จำนวนคงเหลือไม่เปลี่ยน)
  - ระบบ **ย่อรูปให้อัตโนมัติ** ก่อนอัปโหลด (ประหยัดพื้นที่ฐานข้อมูล)
- **ขาด-ลา** (ใหม่): ลาป่วย ลากิจ ลาพักร้อน ลาไม่รับค่าจ้าง ขาดงาน มาสาย — ระบบคำนวณยอดหักให้ (ค่าจ้างรายวัน หรือเงินเดือน÷30, มาสายคิดเป็นนาที) แก้เองได้ ต้องอนุมัติ แล้วจึงไปหักในงวดเงินเดือน
- **เบิกเงินล่วงหน้า** (ใหม่): ขอเบิก → ผู้อนุมัติเลือกบัญชีที่จ่าย → ระบบลงรายจ่ายทันที และหักคืนในงวดเงินเดือน (ตอนจ่ายเงินเดือนลงรายจ่ายแค่ยอดสุทธิ + ประกันสังคม + ภาษี จึงไม่ซ้ำ)
- **ลงเวลา / เช็คอิน GPS** (ใหม่): Admin ตั้งพิกัดร้าน ระยะห่างสูงสุด (เมตร) เวลาเข้างาน และนาทีผ่อนผัน · พนักงานเปิดลิงก์บนมือถือ เลือกชื่อ ใส่ PIN แล้วกดเช็คอิน/เช็คเอาท์ ถ้าอยู่ไกลเกินระบบไม่ให้เช็คอินและบอกว่าห่างกี่เมตร · หัวหน้าดูรายวัน สรุปรายเดือน และเพิ่มรายการเองได้
- **เงินเดือน**: ปุ่ม **“ดึงข้อมูลอัตโนมัติ”** เติมวันทำงานของพนักงานรายวันจากการเช็คอิน + ยอดหักจากการลา + เงินเบิกล่วงหน้า ให้เอง · จ่ายแล้วรายการลา/เบิกจะผูกกับงวดนั้น ไม่หักซ้ำ (ยกเลิกการจ่ายก็ปลดให้)
- **งบการเงิน** (ใหม่): งบกำไรขาดทุน (P&L) และงบแสดงฐานะการเงิน (BS) พิมพ์ได้ — ตั้งได้ว่าแต่ละหมวดอยู่กลุ่มไหนของงบที่เมนู “หมวด & ช่องทาง”
- **หมวด & ช่องทาง ใช้ร่วมกันทุกสาขา** (ใหม่ 2.1): เพิ่ม / เปลี่ยนชื่อ / ลบ / เรียงลำดับ / ตั้งกลุ่มในงบ หมวดหมู่ ช่องทางชำระ ผู้ขาย หน่วยนับ ที่ไหนก็มีผลทุกสาขาพร้อมกัน (เปิด/ปิดได้ที่ ตั้งค่าบริษัท & ระบบ) และมีปุ่ม **คัดลอกจากสาขาหนึ่งไปสาขาอื่น** (รวมรายการสินค้าในสต็อก โดยไม่คัดลอกจำนวนคงเหลือ)
- **บัตรเครดิต & ผ่อนชำระ** (ใหม่ 2.2, ปรับ 2.4):
  - บันทึกรายจ่าย/สินทรัพย์ → เลือกช่องทาง **บัตรเครดิต** (หรือช่องทางเครดิตอื่น) → ระบบถาม **ชำระเต็มจำนวน** หรือ **ผ่อนชำระ**
  - ผ่อนชำระ: ใส่ **ผ่อนกี่งวด** · **จ่ายทุกวันที่เท่าไหร่ของเดือน** · เริ่มงวดแรกเดือนไหน (ระบบเลือกให้) · ดอกเบี้ยรวม (ถ้ามี) — เห็นตารางผ่อนก่อนกดบันทึก
  - เอกสารงวดผ่อนแก้/ลบทีละใบไม่ได้ (กันตารางผ่อนไม่ครบ) — เปิดเอกสารงวดใดก็ได้ จะมีปุ่ม **แก้ไขแผนผ่อน** (ถ้ายังไม่ได้ชำระงวดไหน) และ **ยกเลิกแผนผ่อน** ที่ด้านล่าง หรือทำที่เมนูบัตรเครดิต
  - **ค่าใช้จ่ายลงเดือนละงวด ตามวันที่จ่ายแต่ละงวด** — ไม่ลงเต็มจำนวนในเดือนที่คีย์ (ดอกเบี้ยแยกเป็นเอกสารรายจ่ายของงวดเดียวกัน)
  - ตั้งค่าบัตร (วันตัดรอบ/วันครบกำหนด/วงเงิน) ไม่บังคับ — ถ้าตั้งไว้ ระบบใช้วันครบกำหนดเป็นค่าเริ่มต้นของ “จ่ายทุกวันที่” และคำนวณวันครบกำหนดของการจ่ายเต็มจำนวนให้
  - เมนู **บัตรเครดิต & ผ่อนชำระ**: บิลรายเดือน แผนผ่อนพร้อมความคืบหน้า ประวัติการชำระ วงเงินคงเหลือ
  - **แจ้งเตือน** งวด/บิลที่ครบกำหนดภายใน 7 วันหรือเลยกำหนด (ตัวเลขแดงบนเมนู + การ์ดในหน้าภาพรวม)
  - กด **ชำระบิล** → เลือกจ่ายจากเงินสด/บัญชีไหน → ระบบตัดยอดบัญชีนั้น · ใส่ดอกเบี้ย/ค่าปรับได้ · ยกเลิกการชำระได้
- **รออนุมัติ** (ใหม่): รวมรายการสต็อก / ลา / เบิกเงินที่รอพิจารณาไว้หน้าเดียว พร้อมตัวเลขแจ้งเตือนบนเมนู
- **Log การใช้งาน** (ใหม่): ใคร ทำอะไร สาขาไหน เมื่อไร อย่างไร (IP, อุปกรณ์/เบราว์เซอร์, พิกัดตอนเช็คอิน) รวมการใส่รหัสผิดและการพยายามเข้าสาขา/เมนูที่ไม่มีสิทธิ์ · ดาวน์โหลด CSV ได้
- **ความปลอดภัย**: รหัสผ่านและ PIN เก็บแบบเข้ารหัส (scrypt) ใส่ผิด 5 ครั้งล็อก 5 นาที และออกจากระบบอัตโนมัติเมื่อไม่ใช้งานนาน

## อัปเดตจากเวอร์ชันเดิม (1.0 / 2.x → 3.0) — ข้อมูลเดิมไม่หาย

ระบบจะ **เพิ่ม** ตารางและคอลัมน์ใหม่ให้เองตอนเริ่มทำงาน ไม่ลบหรือแก้ข้อมูลเดิม รหัสผ่านสาขาทุกสาขาและรหัส Admin ใช้ได้เหมือนเดิม
แนะนำให้ **ดาวน์โหลดไฟล์สำรองข้อมูลก่อนอัปเดต** (Admin → สำรองข้อมูล)

### วิธีอัปโหลดไฟล์ใหม่ทับใน GitHub (ทีละขั้น)

1. แตกไฟล์ zip ที่ได้รับ จะได้โฟลเดอร์ `restaurant-accounting` ข้างในมี `server.js`, `package.json`, `README.md` และโฟลเดอร์ `public`
2. เปิด https://github.com แล้วเข้า repo ระบบบัญชี (เช่น `restaurant-accounting`)
3. กดปุ่ม **Add file** (มุมขวาบน เหนือรายชื่อไฟล์) → เลือก **Upload files**
4. เปิดโฟลเดอร์ที่แตกไว้ในเครื่อง **เลือกทุกอย่างข้างใน** (`server.js`, `package.json`, `README.md` และ **โฟลเดอร์ `public` ทั้งโฟลเดอร์**) แล้วลากไปวางในหน้าเว็บ
   - ต้องลาก **ของข้างในโฟลเดอร์** ไม่ใช่ลากตัวโฟลเดอร์ `restaurant-accounting` (ไม่อย่างนั้นจะได้โฟลเดอร์ซ้อน)
   - ไฟล์ชื่อเดิมจะถูกแทนที่อัตโนมัติ
5. รอจนรายชื่อไฟล์ขึ้นครบ (ควรเห็น `public/app.js`, `public/app.css`, `public/index.html`, `server.js`, `package.json`, `README.md`)
6. เลื่อนลงล่าง ช่อง Commit พิมพ์ เช่น `อัปเดตเวอร์ชัน 2.0` → กด **Commit changes**
7. Railway จะ deploy ใหม่ให้เอง (ประมาณ 1–3 นาที) ดูได้ที่ Railway → service ของแอป → แท็บ **Deployments** ต้องขึ้น **Success / Active**
8. เปิด `https://ลิงก์ของคุณ/api/health` ต้องเห็น `"connected": true` และ `"build": "3.0.0"`
9. เปิดหน้าเว็บแล้วกด **รีเฟรช** (บนมือถือ/iPad ถ้ายังเห็นหน้าเก่า ให้ปิดแท็บแล้วเปิดใหม่)

> ถ้าตรวจใน GitHub แล้วเห็นโฟลเดอร์ `restaurant-accounting` ซ้อนอยู่ข้างใน แปลว่าลากผิด — ลบโฟลเดอร์ซ้อนนั้นทิ้ง แล้วทำขั้นที่ 3–6 ใหม่

### หลังอัปเดต — ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. **สร้างผู้ใช้ให้พนักงาน**: Admin → **ผู้ใช้งาน & สิทธิ์** → เพิ่มผู้ใช้ → ตั้งชื่อผู้ใช้ + รหัสชั่วคราว → เลือกสาขา → เลือกสิทธิ์ (กดชุดสำเร็จรูปก็ได้) → ติ๊กสิทธิ์อนุมัติถ้าเป็นผู้จัดการ
   - ตัวอย่าง: พนักงานร้าน → กด “พนักงานร้าน (สต็อกอย่างเดียว)” → พนักงานจะเห็นแค่เมนูสต็อก และทุกการเพิ่ม/ลดต้องรอผู้จัดการอนุมัติ
2. **เปิดระบบเช็คอิน**: Admin → **จัดการสาขา** → ปุ่ม **เช็คอิน** ของสาขา → ยืนอยู่ที่ร้านแล้วกด “ใช้ตำแหน่งปัจจุบัน” (หรือใส่พิกัดจาก Google Maps) → ตั้งระยะห่าง (แนะนำ 100–150 เมตร) เวลาเข้างาน นาทีผ่อนผัน → ติ๊กเปิดใช้ → บันทึก → คัดลอกลิงก์ส่งให้พนักงาน (หรือทำเป็น QR ติดหน้าร้าน)
3. **ตั้ง PIN พนักงาน**: เข้าสาขา → **พนักงาน** → เปิดแต่ละคน → ช่อง PIN (4–6 หลัก) → บันทึก
4. **ทำหมวดให้เหมือนกันทุกสาขา** (ทำครั้งเดียว): Admin → **หมวด & ช่องทาง** → ปุ่ม **คัดลอกจากสาขาหนึ่งไปสาขาอื่น** → ต้นทาง = สาขาที่ใส่ข้อมูลครบแล้ว → ติ๊กสาขาปลายทาง → **คัดลอก** · หลังจากนั้นเพิ่ม/แก้ที่สาขาไหนก็มีผลทุกสาขาเอง
5. **ตั้งค่าบัตรเครดิต**: เข้าสาขา → **หมวด & ช่องทาง** → แท็บ **ช่องทางชำระเงิน** → เพิ่มบัตรแต่ละใบ (ติ๊ก “มีวันครบกำหนด”) → กด **ตั้งค่าบัตร** ใส่วันตัดรอบ/วันครบกำหนดตามใบแจ้งยอด (ตั้งครั้งเดียวมีผลทุกสาขา)
   - ผู้ใช้ที่สร้างไว้ก่อน 2.2 ยังไม่มีสิทธิ์เมนู “บัตรเครดิต” — Admin ไปเปิดสิทธิ์ให้ที่ ผู้ใช้งาน & สิทธิ์
6. **ตั้งกลุ่มงบการเงิน** (ไม่บังคับ): เข้าสาขา → **หมวด & ช่องทาง** → แท็บหมวดรายรับ/รายจ่าย/สินทรัพย์ → เลือก “กลุ่มในงบ” ของแต่ละหมวด (ถ้าไม่เลือก ระบบเดาจากชื่อให้ เช่น วัตถุดิบ → ต้นทุนขาย, เงินเดือน → ค่าใช้จ่ายพนักงาน)

## การเข้าใช้งาน

| ใคร | เข้าอย่างไร | เห็นอะไร |
|---|---|---|
| เจ้าของ / Admin | ปุ่ม **ผู้ดูแลระบบ (Admin)** ใส่ User/Password ทุกครั้ง | ทุกสาขา ทุกเมนู ตั้งค่าทุกอย่าง |
| ผู้จัดการสาขา | เลือกสาขา → **เว้นชื่อผู้ใช้ว่าง** → ใส่ **รหัสผ่านสาขา** (แบบเดิม) | ทุกเมนูของสาขานั้น + อนุมัติได้ทั้งหมด |
| ผู้ใช้ที่ Admin สร้าง | เลือกสาขา → ใส่ **ชื่อผู้ใช้ + รหัสผ่าน** | เฉพาะเมนูและสาขาที่ได้รับสิทธิ์ |
| พนักงาน (ลงเวลา) | เปิด **ลิงก์เช็คอิน** ของสาขา → เลือกชื่อ → ใส่ PIN | หน้าเช็คอิน/เช็คเอาท์อย่างเดียว |

## วิธีใช้งานฟีเจอร์ใหม่

**เงินเดือนแบบอัตโนมัติ**: สร้างงวด → กด **ดึงข้อมูลอัตโนมัติ** → ตรวจ/ปรับ OT เบี้ยเลี้ยง → **จ่ายเงินเดือน**
- พนักงานรายวัน: วันทำงาน = จำนวนวันที่เช็คอินในเดือนนั้น (ถ้ามีข้อมูลเช็คอิน) — วันขาด/ลาไม่รับค่าจ้างไม่ถูกนับเป็นวันทำงานอยู่แล้ว ระบบจึงไม่หักซ้ำ
- ช่อง “ขาด/ลา/สาย” = ยอดหักจากรายการลาที่อนุมัติแล้วในเดือนนั้น
- ช่อง “เบิกล่วงหน้า” = เงินเบิกที่อนุมัติแล้ว กำหนดหักคืนในงวดนี้หรือก่อนหน้า และยังไม่เคยหัก

**งบการเงิน** (ตัวเลขไม่รวม VAT, เป็นเกณฑ์ค้างรับค้างจ่ายตามวันที่เอกสาร):
- **P&L**: รายได้จากการขาย − ต้นทุนขาย = กำไรขั้นต้น − ค่าใช้จ่ายขาย/พนักงาน/บริหาร = กำไรจากการดำเนินงาน + รายได้อื่น − ค่าใช้จ่ายอื่น − ภาษีเงินได้ = กำไรสุทธิ
- ติ๊ก “ปรับสินค้าคงเหลือ” = ต้นทุนขาย = สินค้าต้นงวด + ซื้อ + รับเข้าอื่น − สินค้าปลายงวด (ใช้มูลค่าสต็อกจากระบบ)
- **BS**: เงินสด/ธนาคารแต่ละบัญชี ณ วันที่, ลูกหนี้ค้างรับ, สินค้าคงเหลือ, สินทรัพย์ถาวร (ราคาทุน ยังไม่หักค่าเสื่อม), เจ้าหนี้/ค้างจ่าย (แยกบัตรเครดิต), ภาษีมูลค่าเพิ่มสุทธิ, ส่วนของเจ้าของ = ทุน/ยอดยกมา + กำไรสะสม (งบดุลเสมอ)

## ติดตั้งใหม่ตั้งแต่ต้น (ครั้งแรกเท่านั้น)

1. GitHub → **New repository** ชื่อ `restaurant-accounting` → กด “uploading an existing file” → ลากไฟล์ทั้งหมด (รวมโฟลเดอร์ `public`) → **Commit changes**
2. https://railway.app → **New Project** → **Deploy from GitHub repo** → เลือก repo
3. ในโปรเจกต์เดียวกัน **+ New** → **Database** → **Add PostgreSQL**
4. service ของแอป → **Variables** → ต้องมี `DATABASE_URL` (ถ้าไม่มี: **+ New Variable** → **Add Reference** → `DATABASE_URL` ของ Postgres)
5. **Settings** → **Networking** → **Generate Domain**
6. เปิดลิงก์ → **ผู้ดูแลระบบ (Admin)** → User `admin` Password `admin1234` → ระบบบังคับตั้งรหัสใหม่
7. ตั้งค่าบริษัท → สร้างสาขา → สร้างผู้ใช้งาน → ตั้งค่าเช็คอิน

## ลืมรหัสผ่าน
- **ลืมรหัสสาขา**: Admin → จัดการสาขา → ตั้งรหัสใหม่
- **ผู้ใช้ลืมรหัส**: Admin → ผู้ใช้งาน & สิทธิ์ → เปิดผู้ใช้ → รีเซ็ตรหัสผ่าน (ผู้ใช้ต้องตั้งใหม่ตอนเข้า)
- **พนักงานลืม PIN**: เข้าสาขา → พนักงาน → ตั้ง PIN ใหม่
- **ลืมรหัส Admin**: ให้ Admin คนอื่นรีเซ็ตให้ — แนะนำให้มี Admin สำรองอย่างน้อย 1 คน
