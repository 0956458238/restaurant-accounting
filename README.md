# ระบบบัญชีร้านอาหาร (หลายสาขา) — Node.js + PostgreSQL · เวอร์ชัน 2.2

ระบบบัญชีอย่างเดียว (ไม่มีระบบขาย POS) แยกบัญชีตามสาขา ทุกคนต้องเข้าสู่ระบบก่อนใช้งาน และเห็นเฉพาะเมนูที่ได้รับสิทธิ์

## มีอะไรบ้าง

- **หลายสาขา**: Admin สร้างสาขาได้ไม่จำกัด แต่ละสาขามีบัญชี สต็อก พนักงาน และเงินเดือนแยกกัน
- **บัญชี**: รายรับ / รายจ่าย / สินทรัพย์ (หลายบรรทัด ส่วนลด VAT 7% แนบใบเสร็จ) เลขที่เอกสารอัตโนมัติ ค้างรับ-ค้างจ่าย สมุดบัญชี เงินในบัญชี พิมพ์ / PDF / Excel
- **ภาพรวม** (ใหม่):
  - **รายได้เฉลี่ย** — เฉลี่ยต่อวันที่มีรายรับ, เฉลี่ยต่อวันตามปฏิทิน (ช่วงที่ยังไม่จบนับถึงวันนี้), ค่าใช้จ่ายเฉลี่ยต่อวัน, กำไรเฉลี่ยต่อวัน, ยอดเฉลี่ยต่อเอกสาร, วันที่ขายได้สูงสุด/ต่ำสุด และค่าเฉลี่ยแยกตามวันในสัปดาห์
  - **สรุปตามช่องทางรับ/ชำระเงิน** — แต่ละช่องทางรับเท่าไหร่ จ่ายเท่าไหร่ สุทธิเท่าไหร่ แยกช่องทางเครดิต (บัตรเครดิต แอปเดลิเวอรี่รอโอน) และรายการที่ยังค้าง/ไม่ระบุช่องทางออกมาชัดเจน
- **ผู้ใช้งาน & สิทธิ์** (ใหม่): Admin สร้างผู้ใช้ได้หลายคน กำหนดได้ว่าแต่ละคน
  - เข้าสาขาไหนได้ (เลือกหลายสาขา หรือทุกสาขา)
  - แต่ละเมนู **ไม่เห็น / ดูอย่างเดียว / แก้ไขได้** (15 เมนู) — มีชุดสำเร็จรูป เช่น “พนักงานร้าน (สต็อกอย่างเดียว)”
  - เป็นผู้อนุมัติหรือไม่: อนุมัติสต็อก / อนุมัติการลา / อนุมัติเบิกเงิน
  - เซิร์ฟเวอร์ตรวจสิทธิ์ทุกครั้ง (ไม่ใช่แค่ซ่อนเมนู) · ผู้ใช้ใหม่ต้องเปลี่ยนรหัสเมื่อเข้าครั้งแรก · เปลี่ยนรหัสของตัวเองได้
- **สต็อกต้องรออนุมัติ** (ใหม่): ถ้าคนที่ไม่มีสิทธิ์อนุมัติ รับเข้า / เบิก / ของเสีย / ตรวจนับ / ใส่ยอดยกมา รายการจะเป็น “รออนุมัติ” ยังไม่กระทบยอด จนผู้จัดการกดอนุมัติ (ไม่อนุมัติต้องใส่เหตุผล) · รายการที่อนุมัติแล้ว ลบได้เฉพาะผู้อนุมัติ
- **ขาด-ลา** (ใหม่): ลาป่วย ลากิจ ลาพักร้อน ลาไม่รับค่าจ้าง ขาดงาน มาสาย — ระบบคำนวณยอดหักให้ (ค่าจ้างรายวัน หรือเงินเดือน÷30, มาสายคิดเป็นนาที) แก้เองได้ ต้องอนุมัติ แล้วจึงไปหักในงวดเงินเดือน
- **เบิกเงินล่วงหน้า** (ใหม่): ขอเบิก → ผู้อนุมัติเลือกบัญชีที่จ่าย → ระบบลงรายจ่ายทันที และหักคืนในงวดเงินเดือน (ตอนจ่ายเงินเดือนลงรายจ่ายแค่ยอดสุทธิ + ประกันสังคม + ภาษี จึงไม่ซ้ำ)
- **ลงเวลา / เช็คอิน GPS** (ใหม่): Admin ตั้งพิกัดร้าน ระยะห่างสูงสุด (เมตร) เวลาเข้างาน และนาทีผ่อนผัน · พนักงานเปิดลิงก์บนมือถือ เลือกชื่อ ใส่ PIN แล้วกดเช็คอิน/เช็คเอาท์ ถ้าอยู่ไกลเกินระบบไม่ให้เช็คอินและบอกว่าห่างกี่เมตร · หัวหน้าดูรายวัน สรุปรายเดือน และเพิ่มรายการเองได้
- **เงินเดือน**: ปุ่ม **“ดึงข้อมูลอัตโนมัติ”** เติมวันทำงานของพนักงานรายวันจากการเช็คอิน + ยอดหักจากการลา + เงินเบิกล่วงหน้า ให้เอง · จ่ายแล้วรายการลา/เบิกจะผูกกับงวดนั้น ไม่หักซ้ำ (ยกเลิกการจ่ายก็ปลดให้)
- **งบการเงิน** (ใหม่): งบกำไรขาดทุน (P&L) และงบแสดงฐานะการเงิน (BS) พิมพ์ได้ — ตั้งได้ว่าแต่ละหมวดอยู่กลุ่มไหนของงบที่เมนู “หมวด & ช่องทาง”
- **หมวด & ช่องทาง ใช้ร่วมกันทุกสาขา** (ใหม่ 2.1): เพิ่ม / เปลี่ยนชื่อ / ลบ / เรียงลำดับ / ตั้งกลุ่มในงบ หมวดหมู่ ช่องทางชำระ ผู้ขาย หน่วยนับ ที่ไหนก็มีผลทุกสาขาพร้อมกัน (เปิด/ปิดได้ที่ ตั้งค่าบริษัท & ระบบ) และมีปุ่ม **คัดลอกจากสาขาหนึ่งไปสาขาอื่น** (รวมรายการสินค้าในสต็อก โดยไม่คัดลอกจำนวนคงเหลือ)
- **บัตรเครดิต & ผ่อนชำระ** (ใหม่ 2.2):
  - ตั้งค่าแต่ละบัตร: วันตัดรอบ วันครบกำหนดชำระ วงเงิน (หมวด & ช่องทาง → ช่องทางชำระเงิน → ปุ่ม “ตั้งค่าบัตร”) — รูดบัตรแล้วระบบคำนวณวันครบกำหนดให้เอง
  - บันทึกรายจ่าย/สินทรัพย์ผ่านบัตร เลือก **จ่ายเต็มจำนวน** หรือ **แบ่งจ่ายรายเดือน** (2–60 เดือน ใส่ดอกเบี้ย/ค่าธรรมเนียมได้) — ระบบสร้างเอกสารเดือนละงวด ลงค่าใช้จ่ายเดือนละงวดจนครบ
  - เมนู **บัตรเครดิต & ผ่อนชำระ**: บิลรายเดือนของแต่ละบัตร แผนผ่อนพร้อมความคืบหน้า ประวัติการชำระ
  - **แจ้งเตือน** บิลที่ครบกำหนดภายใน 7 วันหรือเลยกำหนด (ตัวเลขแดงบนเมนู + การ์ดในหน้าภาพรวม)
  - กด **ชำระบิล** → เลือกจ่ายจากเงินสด/บัญชีไหน → ระบบตัดยอดบัญชีนั้น · ใส่ดอกเบี้ย/ค่าปรับได้ (ลงรายจ่ายให้อัตโนมัติ) · ยกเลิกการชำระได้
- **รออนุมัติ** (ใหม่): รวมรายการสต็อก / ลา / เบิกเงินที่รอพิจารณาไว้หน้าเดียว พร้อมตัวเลขแจ้งเตือนบนเมนู
- **Log การใช้งาน** (ใหม่): ใคร ทำอะไร สาขาไหน เมื่อไร อย่างไร (IP, อุปกรณ์/เบราว์เซอร์, พิกัดตอนเช็คอิน) รวมการใส่รหัสผิดและการพยายามเข้าสาขา/เมนูที่ไม่มีสิทธิ์ · ดาวน์โหลด CSV ได้
- **ความปลอดภัย**: รหัสผ่านและ PIN เก็บแบบเข้ารหัส (scrypt) ใส่ผิด 5 ครั้งล็อก 5 นาที และออกจากระบบอัตโนมัติเมื่อไม่ใช้งานนาน

## อัปเดตจากเวอร์ชันเดิม (1.0 / 2.x → 2.2) — ข้อมูลเดิมไม่หาย

ระบบจะ **เพิ่ม** ตารางและคอลัมน์ใหม่ให้เองตอนเริ่มทำงาน ไม่ลบหรือแก้ข้อมูลเดิม รหัสผ่านสาขาทุกสาขาและรหัส Admin ใช้ได้เหมือนเดิม
แนะนำให้ **ดาวน์โหลดไฟล์สำรองข้อมูลก่อนอัปเดต** (Admin → สำรองข้อมูล)

### วิธีอัปโหลดไฟล์ใหม่ทับใน GitHub (ทีละขั้น)

1. แตกไฟล์ zip ที่ได้รับ จะได้โฟลเดอร์ `restaurant-accounting` ข้างในมี `server.js`, `package.json`, `README.md` และโฟลเดอร์ `public`
2. เปิด https://github.com แล้วเข้า repo ระบบบัญชี (เช่น `restaurant-accounting`)
3. กดปุ่ม **Add file** (มุมขวาบน เหนือรายชื่อไฟล์) → เลือก **Upload files**
4. เปิดโฟลเดอร์ที่แตกไว้ในเครื่อง **เลือกทุกอย่างข้างใน** (`server.js`, `package.json`, `README.md` และ **โฟลเดอร์ `public` ทั้งโฟลเดอร์**) แล้วลากไปวางในหน้าเว็บ
   - ต้องลาก **ของข้างในโฟลเดอร์** ไม่ใช่ลากตัวโฟลเดอร์ `restaurant-accounting` (ไม่อย่างนั้นจะได้โฟลเดอร์ซ้อน)
   - ไฟล์ชื่อเดิมจะถูกแทนที่อัตโนมัติ
5. รอจนรายชื่อไฟล์ขึ้นครบ (ควรเห็น `public/app.js`, `public/app.css`, `public/index.html`, `server.js`, `package.json`, `README.md`)
6. เลื่อนลงล่าง ช่อง Commit พิมพ์ เช่น `อัปเดตเวอร์ชัน 2.0` → กด **Commit changes**
7. Railway จะ deploy ใหม่ให้เอง (ประมาณ 1–3 นาที) ดูได้ที่ Railway → service ของแอป → แท็บ **Deployments** ต้องขึ้น **Success / Active**
8. เปิด `https://ลิงก์ของคุณ/api/health` ต้องเห็น `"connected": true` และ `"build": "2.2.0"`
9. เปิดหน้าเว็บแล้วกด **รีเฟรช** (บนมือถือ/iPad ถ้ายังเห็นหน้าเก่า ให้ปิดแท็บแล้วเปิดใหม่)

> ถ้าตรวจใน GitHub แล้วเห็นโฟลเดอร์ `restaurant-accounting` ซ้อนอยู่ข้างใน แปลว่าลากผิด — ลบโฟลเดอร์ซ้อนนั้นทิ้ง แล้วทำขั้นที่ 3–6 ใหม่

### หลังอัปเดต — ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. **สร้างผู้ใช้ให้พนักงาน**: Admin → **ผู้ใช้งาน & สิทธิ์** → เพิ่มผู้ใช้ → ตั้งชื่อผู้ใช้ + รหัสชั่วคราว → เลือกสาขา → เลือกสิทธิ์ (กดชุดสำเร็จรูปก็ได้) → ติ๊กสิทธิ์อนุมัติถ้าเป็นผู้จัดการ
   - ตัวอย่าง: พนักงานร้าน → กด “พนักงานร้าน (สต็อกอย่างเดียว)” → พนักงานจะเห็นแค่เมนูสต็อก และทุกการเพิ่ม/ลดต้องรอผู้จัดการอนุมัติ
2. **เปิดระบบเช็คอิน**: Admin → **จัดการสาขา** → ปุ่ม **เช็คอิน** ของสาขา → ยืนอยู่ที่ร้านแล้วกด “ใช้ตำแหน่งปัจจุบัน” (หรือใส่พิกัดจาก Google Maps) → ตั้งระยะห่าง (แนะนำ 100–150 เมตร) เวลาเข้างาน นาทีผ่อนผัน → ติ๊กเปิดใช้ → บันทึก → คัดลอกลิงก์ส่งให้พนักงาน (หรือทำเป็น QR ติดหน้าร้าน)
3. **ตั้ง PIN พนักงาน**: เข้าสาขา → **พนักงาน** → เปิดแต่ละคน → ช่อง PIN (4–6 หลัก) → บันทึก
4. **ทำหมวดให้เหมือนกันทุกสาขา** (ทำครั้งเดียว): Admin → **หมวด & ช่องทาง** → ปุ่ม **คัดลอกจากสาขาหนึ่งไปสาขาอื่น** → ต้นทาง = สาขาที่ใส่ข้อมูลครบแล้ว → ติ๊กสาขาปลายทาง → **คัดลอก** · หลังจากนั้นเพิ่ม/แก้ที่สาขาไหนก็มีผลทุกสาขาเอง
5. **ตั้งค่าบัตรเครดิต**: เข้าสาขา → **หมวด & ช่องทาง** → แท็บ **ช่องทางชำระเงิน** → เพิ่มบัตรแต่ละใบ (ติ๊ก “มีวันครบกำหนด”) → กด **ตั้งค่าบัตร** ใส่วันตัดรอบ/วันครบกำหนดตามใบแจ้งยอด (ตั้งครั้งเดียวมีผลทุกสาขา)
   - ผู้ใช้ที่สร้างไว้ก่อน 2.2 ยังไม่มีสิทธิ์เมนู “บัตรเครดิต” — Admin ไปเปิดสิทธิ์ให้ที่ ผู้ใช้งาน & สิทธิ์
6. **ตั้งกลุ่มงบการเงิน** (ไม่บังคับ): เข้าสาขา → **หมวด & ช่องทาง** → แท็บหมวดรายรับ/รายจ่าย/สินทรัพย์ → เลือก “กลุ่มในงบ” ของแต่ละหมวด (ถ้าไม่เลือก ระบบเดาจากชื่อให้ เช่น วัตถุดิบ → ต้นทุนขาย, เงินเดือน → ค่าใช้จ่ายพนักงาน)

## การเข้าใช้งาน

| ใคร | เข้าอย่างไร | เห็นอะไร |
|---|---|---|
| เจ้าของ / Admin | ปุ่ม **ผู้ดูแลระบบ (Admin)** ใส่ User/Password ทุกครั้ง | ทุกสาขา ทุกเมนู ตั้งค่าทุกอย่าง |
| ผู้จัดการสาขา | เลือกสาขา → **เว้นชื่อผู้ใช้ว่าง** → ใส่ **รหัสผ่านสาขา** (แบบเดิม) | ทุกเมนูของสาขานั้น + อนุมัติได้ทั้งหมด |
| ผู้ใช้ที่ Admin สร้าง | เลือกสาขา → ใส่ **ชื่อผู้ใช้ + รหัสผ่าน** | เฉพาะเมนูและสาขาที่ได้รับสิทธิ์ |
| พนักงาน (ลงเวลา) | เปิด **ลิงก์เช็คอิน** ของสาขา → เลือกชื่อ → ใส่ PIN | หน้าเช็คอิน/เช็คเอาท์อย่างเดียว |

## วิธีใช้งานฟีเจอร์ใหม่

**เงินเดือนแบบอัตโนมัติ**: สร้างงวด → กด **ดึงข้อมูลอัตโนมัติ** → ตรวจ/ปรับ OT เบี้ยเลี้ยง → **จ่ายเงินเดือน**
- พนักงานรายวัน: วันทำงาน = จำนวนวันที่เช็คอินในเดือนนั้น (ถ้ามีข้อมูลเช็คอิน) — วันขาด/ลาไม่รับค่าจ้างไม่ถูกนับเป็นวันทำงานอยู่แล้ว ระบบจึงไม่หักซ้ำ
- ช่อง “ขาด/ลา/สาย” = ยอดหักจากรายการลาที่อนุมัติแล้วในเดือนนั้น
- ช่อง “เบิกล่วงหน้า” = เงินเบิกที่อนุมัติแล้ว กำหนดหักคืนในงวดนี้หรือก่อนหน้า และยังไม่เคยหัก

**งบการเงิน** (ตัวเลขไม่รวม VAT, เป็นเกณฑ์ค้างรับค้างจ่ายตามวันที่เอกสาร):
- **P&L**: รายได้จากการขาย − ต้นทุนขาย = กำไรขั้นต้น − ค่าใช้จ่ายขาย/พนักงาน/บริหาร = กำไรจากการดำเนินงาน + รายได้อื่น − ค่าใช้จ่ายอื่น − ภาษีเงินได้ = กำไรสุทธิ
- ติ๊ก “ปรับสินค้าคงเหลือ” = ต้นทุนขาย = สินค้าต้นงวด + ซื้อ + รับเข้าอื่น − สินค้าปลายงวด (ใช้มูลค่าสต็อกจากระบบ)
- **BS**: เงินสด/ธนาคารแต่ละบัญชี ณ วันที่, ลูกหนี้ค้างรับ, สินค้าคงเหลือ, สินทรัพย์ถาวร (ราคาทุน ยังไม่หักค่าเสื่อม), เจ้าหนี้/ค้างจ่าย (แยกบัตรเครดิต), ภาษีมูลค่าเพิ่มสุทธิ, ส่วนของเจ้าของ = ทุน/ยอดยกมา + กำไรสะสม (งบดุลเสมอ)

## ติดตั้งใหม่ตั้งแต่ต้น (ครั้งแรกเท่านั้น)

1. GitHub → **New repository** ชื่อ `restaurant-accounting` → กด “uploading an existing file” → ลากไฟล์ทั้งหมด (รวมโฟลเดอร์ `public`) → **Commit changes**
2. https://railway.app → **New Project** → **Deploy from GitHub repo** → เลือก repo
3. ในโปรเจกต์เดียวกัน **+ New** → **Database** → **Add PostgreSQL**
4. service ของแอป → **Variables** → ต้องมี `DATABASE_URL` (ถ้าไม่มี: **+ New Variable** → **Add Reference** → `DATABASE_URL` ของ Postgres)
5. **Settings** → **Networking** → **Generate Domain**
6. เปิดลิงก์ → **ผู้ดูแลระบบ (Admin)** → User `admin` Password `admin1234` → ระบบบังคับตั้งรหัสใหม่
7. ตั้งค่าบริษัท → สร้างสาขา → สร้างผู้ใช้งาน → ตั้งค่าเช็คอิน

## (ไม่บังคับ) Environment Variables

| ชื่อตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `ADMIN_USER` | `admin` | ชื่อผู้ใช้ Admin คนแรก (ใช้ตอนเปิดระบบครั้งแรกเท่านั้น) |
| `ADMIN_PASS` | `admin1234` | รหัส Admin คนแรก (ระบบบังคับให้เปลี่ยนหลังเข้าครั้งแรก) |

## ลืมรหัสผ่าน
- **ลืมรหัสสาขา**: Admin → จัดการสาขา → ตั้งรหัสใหม่
- **ผู้ใช้ลืมรหัส**: Admin → ผู้ใช้งาน & สิทธิ์ → เปิดผู้ใช้ → รีเซ็ตรหัสผ่าน (ผู้ใช้ต้องตั้งใหม่ตอนเข้า)
- **พนักงานลืม PIN**: เข้าสาขา → พนักงาน → ตั้ง PIN ใหม่
- **ลืมรหัส Admin**: ให้ Admin คนอื่นรีเซ็ตให้ — แนะนำให้มี Admin สำรองอย่างน้อย 1 คน
