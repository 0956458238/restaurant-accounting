# ระบบบัญชีร้านอาหาร (หลายสาขา) — Node.js + PostgreSQL

ระบบบัญชีอย่างเดียว (ไม่มีระบบขาย POS) แยกบัญชีตามสาขา และทุกสาขาต้องใส่รหัสผ่านก่อนเข้าใช้งาน

**มีอะไรบ้าง**
- **หลายสาขา**: Admin สร้างสาขาใหม่ได้ไม่จำกัด แต่ละสาขามีบัญชี สต็อก พนักงาน และเงินเดือนแยกกัน
- **บัญชี**: รายรับ / รายจ่าย / สินทรัพย์-งบลงทุน (หลายบรรทัด หลายหมวด ส่วนลด VAT 7% แนบใบเสร็จหรือรูปได้)
  ใช้เลขที่เอกสารอัตโนมัติ มีค้างรับ-ค้างจ่ายพร้อมวันครบกำหนด สมุดบัญชีที่มียอดคงเหลือสะสม งบกำไรขาดทุนอย่างย่อ และพิมพ์ / PDF / Excel ได้
- **สต็อกสินค้า**: รับเข้า เบิกใช้ ของเสีย ตรวจนับ มีบัตรสต็อก ต้นทุนเฉลี่ย และแจ้งเตือนสินค้าใกล้หมด
  ถ้าบันทึกรายจ่ายแล้ว "ผูกสต็อก" ไว้ ของจะเข้าสต็อกให้อัตโนมัติ
- **เงินเดือน**: เก็บข้อมูลพนักงานรายเดือนและรายวัน คิด OT เบี้ยเลี้ยง โบนัส ขาด/ลา ภาษี และเบิกล่วงหน้า
  ประกันสังคมคำนวณให้อัตโนมัติ (5% สูงสุด 875 บาท) พิมพ์สลิปเงินเดือนได้ 2 ใบต่อหน้า A4
  เมื่อกด "จ่ายเงินเดือน" ระบบจะลงเป็นรายจ่ายให้เอง
- **Admin**: ต้องใส่ User และ Password **ทุกครั้ง** ที่เข้า (ปิดหน้า / ออกจากหน้า Admin แล้วต้องเข้าระบบใหม่)
  ตั้งค่าได้ทุกอย่าง: สาขา, รหัสผ่านสาขา, หมวดและช่องทาง, ข้อมูลบริษัทและโลโก้, ประกันสังคม, ผู้ดูแลหลายคน, ประวัติการใช้งาน และสำรองข้อมูล
- **ความปลอดภัย**: รหัสผ่านเก็บแบบเข้ารหัส (scrypt) ไม่มีใครอ่านรหัสจริงได้ ใส่รหัสผิด 5 ครั้งระบบจะล็อก 5 นาที
  และระบบจะออกจากระบบให้อัตโนมัติเมื่อไม่ได้ใช้งานนาน

## ขั้นตอนที่ 1: สร้างที่เก็บโค้ดบน GitHub (repo ใหม่ แยกจาก POS)

1. ไปที่ https://github.com → กด **+** มุมขวาบน → **New repository**
2. ตั้งชื่อ เช่น `restaurant-accounting` → กด **Create repository**
3. กดลิงก์ **"uploading an existing file"**
4. **ลากไฟล์ทั้งหมดในโฟลเดอร์นี้** ไปวาง ได้แก่ `package.json`, `server.js`, `README.md` และ **โฟลเดอร์ `public` ทั้งโฟลเดอร์** (ข้างในมี `index.html`, `app.js`, `app.css`)
5. กด **Commit changes**

## ขั้นตอนที่ 2: Deploy บน Railway

1. ไปที่ https://railway.app → **New Project** → **Deploy from GitHub repo** → เลือก `restaurant-accounting`
2. ในโปรเจกต์เดียวกัน กด **+ New** (หรือ Create) → **Database** → **Add PostgreSQL**
3. กลับไปที่ service ของแอป (ไม่ใช่ตัวฐานข้อมูล) → แท็บ **Variables** → ตรวจว่ามีตัวแปร `DATABASE_URL` แล้ว
   ถ้ายังไม่มี ให้กด **+ New Variable** → **Add Reference** → เลือก `DATABASE_URL` ของ Postgres
4. แท็บ **Settings** → **Networking** → **Generate Domain** จะได้ลิงก์เว็บ เช่น `restaurant-accounting-production.up.railway.app`

> ใช้ Project ใหม่แยกจาก POS เดิมจะดีที่สุด ฐานข้อมูลจะได้ไม่ปนกัน

## ขั้นตอนที่ 3: เริ่มใช้งาน

1. เปิดลิงก์เว็บ → กด **ผู้ดูแลระบบ (Admin)**
2. เข้าครั้งแรกด้วย **User: `admin`  Password: `admin1234`**
   ระบบจะ **บังคับให้ตั้งรหัสใหม่ทันที** (เปลี่ยนชื่อผู้ใช้ได้ด้วย)
3. ไปที่ **ตั้งค่าบริษัท & ระบบ** → ใส่ชื่อร้าน ที่อยู่ เลขผู้เสียภาษี และอัปโหลดโลโก้
4. ไปที่ **จัดการสาขา** → **สร้างสาขาใหม่** → ตั้งชื่อสาขาและ **รหัสผ่านของสาขา**
5. พนักงานบัญชีของแต่ละสาขาเปิดลิงก์เดียวกัน เลือกสาขาของตัวเอง แล้วใส่รหัสสาขาเพื่อเข้าใช้งาน

## (ไม่บังคับ) Environment Variables

| ชื่อตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `ADMIN_USER` | `admin` | ชื่อผู้ใช้ Admin คนแรก (ใช้ตอนเปิดระบบครั้งแรกเท่านั้น) |
| `ADMIN_PASS` | `admin1234` | รหัส Admin คนแรก (ระบบบังคับให้เปลี่ยนหลังเข้าครั้งแรก) |

## ลืมรหัสผ่าน
- **ลืมรหัสสาขา**: Admin เข้าไปที่ **จัดการสาขา** → **ตั้งรหัสใหม่**
- **ลืมรหัส Admin**: ให้ Admin คนอื่นกด **รีเซ็ตรหัส** ให้ ถ้ามี Admin คนเดียว แนะนำให้เพิ่ม Admin สำรองไว้อีก 1 คนที่เมนู **ผู้ดูแลระบบ**

## ตรวจสอบว่าระบบทำงาน
เปิด `https://ลิงก์ของคุณ/api/health` ถ้าเห็น `"connected": true` แปลว่าเชื่อมฐานข้อมูลสำเร็จ
